# Note市場調査レポート（Phase 1）

- 作成日：2026-10-26
- 対象：noteの有料記事（1記事500円を基本）で、知的・人文系の読み物メディアを立ち上げる場合の市場性
- 位置づけ：**初回調査**。販売実績のない段階の仮説であり、収益を保証するものではない
- 機械可読データ：`genres/candidates/genre_scores_2026-10-26.csv`（ジャンル評価）、`ideas/backlog/ideas.csv`（記事企画100本）

---

## 0. 要約

1. **市場は伸びているが、伸びているのは「実用」側。** note公式の分析（2026年1月公表）によると、有料記事の売上は前年同月比で伸びている。急成長しているジャンルは「AI活用」「SNS運用」「育児」など、収入アップや課題解決に直結するもの。読み物系の平均価格（売上上位20%の記事）は983円で、実用ノウハウ系の1,842円の約半分だった。
2. **それでも人文・教養の読み物には需要の裏付けがある。** 書籍市場では哲学・人文書の一般向けヒットが続いている。『自分とか、ないから。』は12.6万部（電子含む、報道時点）、『センスの哲学』は10万部突破、『暇と退屈の倫理学』の文庫版は14万部突破、『なぜ働いていると本が読めなくなるのか』は新書大賞2025を受賞。歴史ポッドキャストのCOTEN RADIOは累計5,500万回再生とされる。どの数字も出版社・媒体の発表値。
3. **勝ち筋は「教養の要約」ではなく「確かめる教養」。** 通説・流行の概念を一次資料と研究の質から読み直し、複数の分野を掛け合わせて新しい見方を出す。この方向は競合が少なく、500円の対価も説明しやすい。
4. **上位5ジャンル（暫定）**
   1. 検証する心理学（80点）
   2. 時間・退屈・労働の哲学（77点）
   3. 美学×デザイン（76点）
   4. AI時代の人間論（73点）
   5. 生物学から人間関係を考える（71点）
5. **5ジャンルは一つのブランドに束ねる。** 束ねる軸は「見方を変える／確かめる」。雑記アカウントにはしない。ブランド案は `brand/brand_proposal.md`。
6. **月10万円（売上）には月200部、30万円には月600部が必要（500円換算）。** 1記事あたりの月間販売数は取得できていない。そのため必要な記事本数は幅でしか示せない（§6）。

## 1. 調査方法と制約

### 1.1 実施した方法

| 調査対象（要件） | 実施内容 | 取得状況 |
|---|---|---|
| 1. note内の人気記事 | Web検索経由でnote公式発表と解説記事を確認 | **部分的**（note.com本体へのアクセス不可） |
| 2. note内の有料記事 | note公式の「約30万件の有料記事分析」（2026-01-07公表）の報道を確認 | 二次情報 |
| 3. 有料記事の価格帯 | 公式分析の平均価格、個人分析（100件調査）を確認 | 二次情報 |
| 4. 競合アカウント | 検索で哲学系・教養系の事例を探索 | **ほぼ取得不能** |
| 5. 競合の投稿頻度 | — | **取得不能** |
| 6. 読者コメント・反応 | — | **取得不能** |
| 7. Google検索需要 | Googleトレンドやキーワードツールは利用不可 | **取得不能**（代替指標で推定） |
| 8. SNSでの話題性 | YouTube・ポッドキャストの規模を検索で確認 | 部分的 |
| 9. 関連書籍・専門メディア | 書籍の部数・受賞を検索で確認 | 取得（出版社発表値） |
| 10. 既存記事で不足している考察 | 学術レビュー（色彩心理、再現性問題など）を確認 | 部分的 |

### 1.2 重要な制約（推測で補っていない点）

- **この作業環境のネットワーク設定で、`note.com`、`prtimes.jp` などへの直接アクセスが遮断されている**（プロキシが403を返した）。そのため、ページ本文の確認、note内検索、ランキング閲覧、記事ごとの「スキ」数の取得はできていない。利用したのは検索エンジンの結果要約だけ。
- **競合アカウントの具体名・フォロワー数・投稿頻度・コメント内容は取得できていない。** 本レポートの「競合の状況」は、検索で見つかった事例の少なさや書籍市場の状況から推定したもので、**推定**と明記している。
- **検索需要の数値（月間検索数など）は取得できていない。** 代わりに次の代替指標で需要を推定した。
  - 書籍の部数・受賞
  - ポッドキャスト・YouTubeの規模
  - note公式の成長ジャンル発表
- **ジャンル評価の点数は編集判断であり、測定値ではない。** 根拠は各ジャンルの「調査根拠」に記載した。
- スクレイピングやアクセス制限の回避は行っていない。

### 1.3 次回調査で精度を上げる方法（推奨）

- 環境のネットワーク許可リストに `note.com` を追加してもらえれば、note内の公開ページ（ランキング、ハッシュタグ、有料記事の価格表示）を**手動に近い頻度で閲覧**できる。利用規約の確認を前提とする。
- Googleトレンドとnoteの検索結果件数は、人間がブラウザで確認して `research/trends/` に記録する運用が現実的。
- 最も確実なデータは**自分のアカウントの販売実績**。最初の10〜20記事を「市場調査を兼ねた実験」と位置づける（§6.4）。

## 2. note市場の基礎データ

### 2.1 note公式の有料記事分析（2026年1月7日公表）

検索で確認できた公表内容（報道・解説記事経由）：

- 対象：約30万件の有料記事・メンバーシップ（2024年12月〜2025年11月）。報道によっては「2025年1〜10月に売上のあった約26万件」と記載されており、対象範囲の表記に揺れがある。
- 有料記事の売上は前年同月比 **+26.8%**、メンバーシップは **+81.3%**（2025年11月時点）。売上が発生したクリエイター数も約2倍とされる。
- 急成長ジャンル：「AI活用」「SNS運用」「育児」など、収入アップや課題解決につながるもの。
- 売上上位20%の記事の平均価格：**実用ノウハウ系 1,842円、読み物系 983円**。
- 文字数と売上の相関はほぼゼロ（実用系 -0.023、読み物系 0.011）。
- 個人の分析（有料記事100件）では、価格の最頻値は300円、中央値は399円、500円以下が65%とされる（調査方法は未確認）。

**示唆**

- 読み物系の上位記事は平均で約1,000円で売れている。500円は「上位の読み物」の相場より低い価格設定になる。買いやすさは利点だが、1部あたりの収益は薄い（§6）。
- 文字数を増やしても売上は増えない。要件の「文字数を目的化しない」と整合する。
- メンバーシップの伸びが大きい。単発記事のストックに加えて、将来の拡張先として有力。

### 2.2 手数料（note公式ヘルプ、検索経由で確認。最新料率は公開前に再確認すること）

- 事務手数料：購読者の決済手段で決まる。クレジットカード5%、携帯キャリア決済15%、PayPay 7%、noteポイント10%など。
- プラットフォーム利用料：事務手数料を引いた額の10%（有料記事・有料マガジン・メンバーシップ）。定期購読マガジンは20%。
- 振込手数料：1回270円。

|---|---:|---:|---:|
| クレジットカード | 25円 | 47.5円 | **約428円** |
| PayPay | 35円 | 46.5円 | 約419円 |
| 携帯キャリア | 75円 | 42.5円 | 約383円 |

### 2.3 Noteへの投稿手段

- **公式に公開された投稿APIは確認できなかった。** 非公式API（セッションCookie利用）やブラウザ自動操作で投稿するツールは存在するが、規約上の位置づけは不明で、認証切れなどの不具合も報告されている。
- AI生成コンテンツについてのnote公式ガイドラインは、今回の検索では原文を確認できなかった。
- **方針：投稿は自動化しない。** システムは「note投稿用Markdown＋有料ライン位置の指示＋メタデータ」を出力する。人間が承認したうえで、noteエディタに手動で貼り付けて公開する（Phase 3で実装）。

**全体の示唆**：一般向け人文書のヒットには三つの型がある。
- 「生活の切実な問い × 学問的な裏付け × 平易な語り口」
- 「既存ジャンルの掛け合わせ」（労働×読書史、哲学×センスなど）
- note発の『自分とか、ないから。』

一方、note内では実用系が成長の中心にある。読み物で勝つには、**「読むと見方が変わる」という効用を明確に打ち出すこと**が必要。

### 4.2 上位5ジャンルの詳細

#### G05 検証する心理学（80点）

- **想定読者**：心理学本・自己啓発書を読んできた20〜40代の社会人、教育・人材育成に関わる人。
- **悩み・知的欲求**：「意志力は有限」「マシュマロ・テスト」「メラビアンの法則」などの話をどこまで信じてよいのか知りたい。
- **競合の状況（推定）**：心理学の雑学・ライフハック記事は非常に多い。一方、再現性や研究の質から通説を検証する一般向けの記事は少ないとみられる。日本語での体系的な一般向け解説は、検索では見つからなかった。
- **差別化**：
  - 各知見に「確度ラベル」（確立／有力／議論あり／否定的）を付ける。
  - 原論文と追試を対にして紹介する。
  - 「なぜその通説が広まったか」も分析する。
- **検索需要**：数値は未取得。有名な心理学用語は一般の認知度が高い（推定）。
- **有料記事として成立する理由**：一次文献を読む手間の代行と、正確な理解の提供に明確な価値がある。読者が研修や会話で使える。
- **記事テーマ例**：自我消耗理論の20年、マシュマロ・テスト、スタンフォード監獄実験の再読、ダニング＝クルーガー効果の誤用。
- **収益化の可能性**：シリーズ化しやすく、「科学の読み方」という基礎記事から有料記事へ読者を導く導線が作れる。将来は講座・書籍化へ展開できる。
- **リスク**：研究者の名誉に関わる記述は慎重に扱う。最新の追試状況を確認する負荷が高い。
- **調査根拠**：Open Science Collaboration (2015)、国内の科研費プロジェクト、日本社会心理学会誌の総説（2022）、色彩心理のレビュー（Elliot 2015）、『行動経済学が最強の学問である』の部数。

#### G03 時間・退屈・労働の哲学（77点）

- **想定読者**：忙しさや燃え尽きを感じる会社員、読書の時間を取り戻したい人。
- **悩み・知的欲求**：「なぜこんなに忙しいのか」「休むことに罪悪感がある」「何もしない時間に耐えられない」。
- **競合の状況（推定）**：時間術・生産性の記事は多い。哲学・歴史・社会学から問い直すnote記事は限られる。話題書との重複を避ける必要がある。
- **差別化**：
  - 古典（セネカ、パスカル、アリストテレス）と歴史研究（時間規律の誕生）を組み合わせる。
  - 現代思想（ハン、ローザ）と心理学実験も組み合わせる。
  - 話題書は要約せず、「その先の問い」を扱う。
- **検索需要**：数値は未取得。関連書籍は長期にわたって売れている（『暇と退屈の倫理学』、新書大賞2025）。
- **有料記事として成立する理由**：自分の生活の見方が変わるという効用が明確。複数の古典をつなぐ編集には手間がかかる。
- **記事テーマ例**：暇に耐えられない理由、時計と時間規律の誕生、ケインズの週15時間労働の予言、疲労社会。
- **収益化の可能性**：社会人の切実な悩みと直結するため、購入動機が強い。
- **調査根拠**：§3の書籍データ、Real Soundの哲学本ヒット分析。

#### G06 美学×デザイン（76点）

- **想定読者**：デザイナー、デザイン学習者、暮らし・道具・建築に関心がある層。
- **悩み・知的欲求**：「センスとは何か」「黄金比は本当に美しいのか」「なぜこのデザインは心地よいのか」。
- **競合の状況（推定）**：デザインの実務ノウハウは多い。美学（哲学）と実験心理学を往復する一般向けの解説は少ない。日本語の一般向け「デザイン美学」書籍は検索で特定できなかった。
- **差別化**：
  - 美学史（カント、ヒューム、柳宗悦）と実証研究（単純接触効果、処理の流暢性）を接続する。
  - 黄金比や色彩心理などのデザイン通説を検証する（G05の方法を応用）。
- **検索需要**：数値は未取得。『センスの哲学』10万部が関心の存在を示す。
- **有料記事として成立する理由**：実務者にとって言語化の道具になる（説明・提案に使える）。
- **記事テーマ例**：「センスがいい」とは何か、黄金比の検証、アフォーダンスの正しい理解、民藝の「用の美」。
- **収益化の可能性**：デザイナー層は学習投資に積極的とみられる（推定）。図版との相性も良い。
- **リスク**：図版の著作権。図版は自作するか、権利処理済みの素材に限る。

#### G18 AI時代の人間論（73点）

- **想定読者**：AIを業務で使う社会人、AIの社会的影響に関心のある知的読者。
- **悩み・知的欲求**：「AIは考えているのか」「AIに頼ると思考力は落ちるのか」「人間らしさとは何か」。
- **競合の状況（推定）**：AI関連の記事はnoteの成長ジャンルで、非常に多い。ただし大半は実用（使い方）。哲学・認知科学からの考察は少数とみられる。
- **差別化**：
  - チューリング、サール、プラトン『パイドロス』などの原典を読む。
  - 認知的オフローディングや自動化バイアスの研究を組み合わせる。
  - 「AIの使い方」ではなく「AIを使う人間の変化」を扱う。
- **検索需要**：AI関連は公式分析で急成長ジャンル。人文的な関心がどれだけあるかは未測定。
- **有料記事として成立する理由**：成長ジャンルの読者に、実用書にない視点を提供できる。
- **記事テーマ例**：チューリング原論文の再読、中国語の部屋、記憶の外部化の2400年、ELIZAの教訓。
- **収益化の可能性**：AI関心層の流入が見込める。競合が多いため、独自性の維持が条件。
- **リスク**：技術の変化が速く、記事の陳腐化が早い。原典・歴史を軸にして、ストック性を確保する。

#### G09 生物学から人間関係を考える（71点）

- **想定読者**：人間関係・子育て・職場に悩む人、生き物の話が好きな読者（『生き物の死にざま』の読者層）。

- **競合の状況（推定）**：進化心理学のポップな解説は一定数ある。安易な「本能論」が多く、方法論的な慎重さを持つ記事は少ないとみられる。
- **差別化**：
  - 自然主義の誤謬（自然＝正しい、ではない）を明示する。
  - 適応主義への批判を併記し、類推の限界も検討する。
  - 確度ラベルを付ける。
- **有料記事として成立する理由**：身近な悩みを科学と思想の両面から考えられる。
- **記事テーマ例**：ダンバー数の検証、チンパンジーの政治学、共同養育仮説、愛着理論の広まりと限界。
- **リスク**：性差・子育てなど、価値判断を含むテーマで誤解を招くおそれ。事実と規範を厳密に分ける。

## 6. 収益化の可能性

### 6.1 目標に必要な販売数

| 月間売上目標 | 必要販売数（500円） | 手取りの目安（カード決済、振込手数料前） |
|---:|---:|---:|
| 10万円 | 200部 | 約8.6万円 |
| 20万円 | 400部 | 約17.1万円 |
| 30万円 | 600部 | 約25.7万円 |

### 6.2 必要な記事本数（ストック型の試算）

**読み物系の「1記事あたり月間販売数」は取得できなかった。** そのため仮定値ごとに試算する。

| 1記事あたりの平均月間販売数（仮定） | 月10万円に必要な有料記事数 | 月30万円に必要な有料記事数 |
|---:|---:|---:|
| 1部 | 200本 | 600本 |
| 3部 | 67本 | 200本 |
| 5部 | 40本 | 120本 |
| 10部 | 20本 | 60本 |

**解釈**：
- 週2本ペース（年約100本）なら、1記事あたり月2部の平均で、1年後に月10万円に届く計算になる。
- 月30万円には、より高い購入率か、価格設計の工夫が必要になる可能性が高い。
- 「有料記事で売上を得ているクリエイターは1割未満」とする記述もある（個人解説記事。根拠は未確認）。**初期の数か月は売上がほぼゼロであることも想定に入れる。**

### 6.3 価格設計の論点（要相談）

基本価格は指示通り500円とする。そのうえで、データに基づく検討余地を示す。

1. 読み物系の上位20%の平均価格は983円。500円は「買いやすい価格」として初期の購入数を増やす役割を担う。
2. **シリーズの有料マガジン化**（例：「検証する心理学」5本セットを1,500〜2,000円）は、1購入あたりの単価を上げる有力な手段。
3. **メンバーシップ**は前年比+81%と伸びている。月額500円前後で「全記事読み放題＋参考文献リスト＋研究の続報」といった設計が考えられる。継続課金は月10〜30万円の安定化に効果が大きい。ただし更新頻度の維持が条件。
4. 価格の変更は、最初の20本の販売データを見てから判断する（成功パターンを先に断定しない）。

### 6.4 最初の20本の実験設計（提案）

- 構成：G05から8本、G03から6本、G06・G18・G09から各2本。うち3〜4本は無料。
- 比較する変数：ジャンル、タイトルの型（問い型／検証型／古典型）、無料部分の長さ。
- 記録する指標：閲覧数、購入数、購入率、スキ、コメント（`analytics/sales/sales.csv` に手動入力）。
- 判定：20本公開後に `/analytics` でジャンル別購入率を比較し、上位5ジャンルの構成を見直す。

## 7. リスクと対応

| リスク | 対応 |
|---|---|
| AI生成記事の品質・誤情報 | リサーチ→ファクトチェック→4視点編集の工程を必須にする。確認できない情報は「未確認」と明記する |
| 存在しない文献の引用 | 文献は検索で実在を確認したものだけを使う。URLと閲覧日を記録する。未確認の文献は使用禁止 |
| noteの規約・AI利用の扱い | 公開前に、利用規約・ガイドラインの最新版を人間が確認する（この環境からは原文を確認できなかった） |
| AI利用の開示 | 読者の信頼に関わる。開示方針はオーナーの判断事項（§8） |
| 研究者・個人への言及 | 批判は研究の方法と結論に限定し、人格攻撃をしない |
| 図版の著作権 | 自作の図か、権利処理済みの素材だけを使う |
| 実用系に比べて購入動機が弱い | タイトルと無料部分で、「何がわかるか」「どう見方が変わるか」を明示する |
| 5ジャンルへの分散 | 初期はG05・G03に集中する（§5.1） |
