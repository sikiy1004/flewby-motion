# note投稿用データの出力プロンプト

STEP 10（無料部分と有料部分の分割）と STEP 12（note投稿用データの出力）の手順書。

## 前提

- noteの公式な投稿APIは確認できていない（2026-10-26時点の調査）。**自動投稿はしない。**
- 出力するのは、人間がnoteエディタに貼り付けるためのファイル一式。

## STEP 10：分割の確認

1. 下書きに `<!-- PAYWALL -->` がちょうど1つあることを確認する。
2. 無料部分が全体の25〜40%に収まっているか確認する（`scripts/check_article.py` が比率を表示する）。範囲外なら、理由を確認する。
3. 無料部分の末尾に、有料部分で得られる内容が具体的に示されていることを確認する。
4. 有料部分に、無料部分にない追加価値（詳細な分析、独自考察、結論、確度の一覧、参考文献）があることを確認する。

## STEP 12：出力

`python3 scripts/export_note.py articles/drafts/<slug>.md` を実行する。次の2ファイルが `articles/ready_to_publish/` に作られる。

| ファイル | 内容 |
|---|---|
| `<slug>.note.md` | note貼り付け用の本文。front matter を除き、有料ラインの位置に目印の行を入れたもの |
| `<slug>.publish.md` | 公開チェックリスト：タイトル、価格、ハッシュタグ案、マガジン案、有料ラインの位置、公開前の確認項目、承認欄 |

`<slug>.publish.md` のハッシュタグ案とマガジン案は、出力後にメインのセッションが記入する。

## 公開手順（人間が行う。初回の公開時に、実際のnoteの挙動に合わせてこの節を更新すること）

1. `<slug>.publish.md` のチェックリストを確認し、`/approve-article <slug>` を実行する。
2. noteで新規記事を作成し、`<slug>.note.md` の本文を貼り付ける。
3. 見出し・太字・引用・リンクが崩れていないか確認する。※ Markdown の貼り付けがどこまで反映されるかは未確認。崩れる場合は、エディタの書式機能で直す。
4. 有料エリアを設定し、価格を入力する。有料ラインは、目印の行（`――――― ここから有料 ―――――`）の位置に置く。設定後、目印の行は削除する。
5. ハッシュタグとマガジンを設定して公開する。
6. 公開したら、`/mark-published <slug> <noteのURL>` を実行する。
