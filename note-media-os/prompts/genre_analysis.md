# ジャンル分析プロンプト

`/genre-analysis` が使う手順書。

## 入力

- 最新の市場調査（`research/market/` の最新ファイル）
- 前回のジャンル評価（`genres/candidates/` の最新CSV）
- 販売実績（`analytics/reports/latest_genre_stats.csv` があれば）

## 手順

1. 最低20のジャンル候補を挙げる。既存ジャンルをそのまま使わず、領域の掛け合わせを優先する（例：哲学×現代人の心理、美学×デザイン、生物学×人間関係）。興味領域（哲学・自然科学・心理学・人文知・デザイン・アート・美学・認知科学・社会学・文化史）の隣接ジャンルも探す。
2. 各ジャンルを100点満点で採点する。

   | 項目 | 配点 | 採点の観点 |
   |---|---:|---|
   | 市場需要 | 20 | 書籍・ポッドキャスト・note公式の成長ジャンルなどの裏付け。**需要が小さすぎる市場は低く評価する** |
   | 競合の少なさ | 20 | note内で同じ切り口の有料記事が少ないか。確認できなければ推定と明記する |
   | 独自性 | 20 | このメディアの方法（確かめる・掛け合わせる）で、明確に差別化できるか |
   | 500円の価値 | 20 | 一次資料の読み比べと考察に、対価を払う理由があるか |
   | 継続性 | 10 | 20本以上の企画を、重複なく作れるか |
   | 拡張性 | 10 | マガジン・メンバーシップ・書籍化などに広げられるか |

3. 各ジャンルについて、次を書く。
   - ジャンル名、想定読者、読者の悩み・知的欲求
   - 競合の状況、差別化の方法、検索需要
   - 有料記事として成立する理由、記事テーマの例、収益化の可能性
   - 点数、調査根拠と情報源
4. 販売実績がある場合は、`latest_genre_stats.csv` の購入率を「市場需要」の根拠に加える。ただし公開本数が5本未満のジャンルは「データ不足」として扱い、点数に反映しない。
5. 上位5ジャンルを選び、選定理由を書く。

## 出力

- `genres/candidates/genre_scores_YYYY-MM-DD.csv`（列は前回のCSVと同じ）
- `genres/candidates/genre_analysis_YYYY-MM-DD.md`（各ジャンルの詳細）
- 上位5ジャンルが変わる場合は、`genres/selected/top5.md` の変更案を示す。**ファイルは書き換えず、人間の承認を求める。**
