## 選定ジャンル

`genres/selected/top5.md` を参照する。ステータスが `pending_owner_approval` の間も制作はできるが、記事の front matter に `genre_status: provisional` と書く。

## 品質基準

| 項目 | 値 |
|---|---|
| 最終品質スコアの合格点 | 80 / 100（4人の編集者が各25点で採点） |
| 1人の編集者の最低点 | 15 / 25 |
| 未解決のファクト問題（重大） | 0件でなければ不合格 |
| 再執筆の上限 | 2回。超えたら `status: needs_human` にして人間に相談する |
| 有料記事にできる最低スコア | 80。届かない記事は無料記事にするか、廃案にする |

## レビューモード

Proプランには利用量の上限がある。サブエージェント4人の並列レビューは消費量が大きい。

| モード | 内容 | 使いどころ |
|---|---|---|
| `full`（既定） | Editor A〜D を個別のサブエージェントで実行 | 有料記事 |
| `light` | `editor-factcheck` だけをサブエージェントで実行し、残り3視点はメインのセッションで順に確認 | 無料記事、利用上限が近いとき |

現在のモード：`full`

## 利用ツール

| ツール | 用途 | 費用 | 状態 |
|---|---|---|---|
| Claude Code（Proプラン） | 全工程 | 契約内（利用上限あり） | 利用中 |
| WebSearch / WebFetch（Claude Code内蔵） | リサーチ・ファクトチェック | 契約内 | 実行環境のネットワーク設定に依存する。使えない場合は「取得不能」と記録し、人間に資料の提供を頼む |
| Python 3（標準ライブラリのみ） | 採点・重複チェック・品質チェック・売上分析 | 無料 | 利用中 |
| note | 公開・販売 | 販売手数料（事務手数料＋プラットフォーム利用料10%） | **手動で公開**（公式の投稿APIは確認できていない） |

有料APIや外部サービスを追加する場合は、事前にオーナーへ提案して承認を得る。APIキーなどの秘密情報はリポジトリに書かない。

## 手数料（公開前に note ヘルプで最新値を確認する）

| 項目 | 料率 |
|---|---|

| プラットフォーム利用料 | 事務手数料を引いた額の10%（定期購読マガジンは20%） |
| 振込手数料 | 1回270円 |

## 公開ルール

- **Claude Code は記事を公開しない。** note への投稿・予約投稿・非公式APIの利用・ブラウザ自動操作による投稿は行わない。
- 公開できるのは、人間が `/approve-article` で承認し、自分で note に貼り付けた記事だけ。
