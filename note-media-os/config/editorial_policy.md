# 編集方針

すべての企画・リサーチ・執筆・編集はこの方針に従う。人間が更新してよい。

## 1. メディアの思想

> 知っているつもりのことを、確かな知で確かめ直し、別の見方を手渡す。

読者に知識を渡すことが目的ではない。物事の**見方**を一つ増やすことが目的。
読み終えた読者が、「この話はどこまで確かか」「別の分野からはどう見えるか」を自分で考えられるようにする。

## 2. 記事の必須条件

1. **問いが一つ、はっきりしている。** 記事の冒頭で、何を考えるのかが読者にわかる。
2. **二つ以上の分野を掛け合わせる。** 例：哲学×実験心理学、美学×認知科学、歴史研究×労働経済。
3. **一次資料に当たる。** 論文は原典（少なくとも要旨と方法）を確認する。思想家は原著か、定評ある翻訳・研究書を確認する。孫引きを避ける。
4. **知見の確度を示す。** 本文の主要な主張ごとに、次のラベルのどれに当たるかを判断する。記事末に「確度の一覧」を付ける。

   | ラベル | 意味 |
   |---|---|
   | 確立 | 複数の独立した研究・メタ分析で支持され、専門家の間でおおむね合意がある |
   | 有力 | 良質な研究で支持されているが、追試や適用範囲の確認が不十分 |
   | 議論あり | 専門家の間で解釈や再現性が争われている |
   | 否定的 | 大規模な追試やメタ分析で支持されなかった |
   | 学説 | 哲学・思想上の立場や解釈。正誤ではなく、論拠の強さで評価するもの |
   | 筆者の考察 | 本メディアの独自の見解。事実と区別して書く |

5. **独自の考察がある。** 既存の知識の要約で終わらせない。「複数の知識を組み合わせると何が見えるか」を、筆者の考察として明示する。
6. **読者に考える余地を残す。** 結論は断定より見取り図。未解決の問いを一つ残して終える。

## 3. 情報源の扱い

### 優先順位

1. 学術論文（査読付き。メタ分析・系統的レビュー・事前登録された追試を特に重視する）
2. 大学・研究機関の公開資料
3. 専門書・原著（定評ある翻訳を含む）
4. 公的機関の資料
5. 信頼できる専門メディア

一般のブログ・まとめサイト・SNS投稿は、事実の根拠にしない。話題の存在や通説の流布を示す例としてだけ使う。

### 厳守事項

- 存在しない論文・引用・著者・出版情報を作らない。
- 実在を確認していない文献は本文で使わない。確認できなければ「確認できなかった」と書き、その主張を削る。
- 原文を確認していない引用は、引用符で示さない。要約として扱い、「〜によれば」と出典を明示する。
- 事実と仮説、学説と筆者の考察を区別する。
- 一つの研究結果を普遍的な真理として扱わない。研究については、可能な範囲で次を示す。
  - 対象者数
  - 研究方法（実験・観察・調査・メタ分析）
  - 対象集団（国・年齢など）
  - 追試の状況
  - 研究の限界
- 出典にはURL（DOIがあればDOI）と閲覧日を記録する。
- 引用は必要最小限にとどめる。出典を明記し、本文が主、引用が従の関係を守る。翻訳書から長く引用しない。

## 4. 文章

### 目指す文章

- 知的で落ち着いている。静かな書斎で、信頼できる相手と話す距離感。
- 論理的で読みやすい。一文一義を基本にする。
- 適度な余白がある。段落を詰め込みすぎない。
- 装飾が少ない。比喩は理解を助けるときだけ使う。
- 専門用語は、初出で一文の説明を添える。

### 禁止事項

| 種類 | 例（使わない） |
|---|---|
| AI特有の定型導入 | 「〜について解説します」「〜を徹底解説」「皆さんは〜したことがありますか？」 |
| 不自然なまとめの連続 | 「いかがでしたか」「まとめると」「つまり」「結論から言うと」の多用 |
| 過度な煽り | 「衝撃の」「9割が知らない」「人生が変わる」「完全版」「最強の」 |
| 根拠のない断定 | 「科学的に証明された」「脳科学的に正しい」 |
| 水増し | 同じ結論の繰り返し、意味のない前置き、文字数稼ぎの言い換え |
| 無意味な箇条書き | 論理のつながりを箇条書きで分断する |
| 決まり文句 | 「〜と言っても過言ではない」「〜ではないでしょうか」の多用、「深掘り」「紐解く」の多用 |

`scripts/check_article.py` が、これらの一部を機械的に検出する。

### 記事の長さ

テーマに必要な長さで書く。文字数を目的にしない。note公式の分析でも、文字数と売上の相関はほぼゼロだった。目安は有料記事で6,000〜12,000字だが、内容が許すなら短くてよい。

## 5. 記事構成（基本形。テーマに応じて変えてよい）

1. **導入**：読者の興味を引く問い。具体的な場面や事例から入る。
2. **問題提起**：なぜこの問いを考える必要があるのか。
3. **背景**：歴史・思想・研究の経緯。
4. **本論**：具体的な分析と考察。
5. **根拠**：研究・文献・事例（確度ラベル付き）。
6. **独自考察**：複数の知識を組み合わせた新しい視点（「筆者の考察」と明示する）。
7. **現代との接続**：日常生活や社会との関係。
8. **結論**：見取り図と、残された問い。
9. **確度の一覧**（記事末）
10. **参考文献**（記事末。URL・閲覧日つき）

## 6. 無料部分と有料部分

### 無料部分（全体の25〜40%が目安）

- 興味を引く導入と問題提起
- テーマの背景
- 読者が抱える疑問の提示
- 有料部分で何がわかるかの具体的な説明（目次の形で示す）

無料部分だけ読んだ読者にも、「問いが鮮明になった」という価値を残す。無料部分を、購入させるための寸止めにしない。

### 有料部分

- 詳細な解説、専門的な知識、具体的な事例
- 独自の分析と深い考察
- 新しい見方を与える結論
- 確度の一覧と参考文献

有料部分は無料部分の単なる続きにしない。「無料部分で立てた問いに、有料部分で複数分野から答える」という追加価値を明確にする。

### 500円の判定

次の問いのうち一つでも「いいえ」なら、有料記事にしない。無料記事にするか、構想を練り直す。

- 読者は、同じ内容を検索や要約サイトで5分以内に得られないか。
- 一次資料を読み比べた結果が、本文に反映されているか。
- 「筆者の考察」が、既存の文献の言い換えではないか。
- 読み終えた読者が、誰かに話したくなる視点が一つ以上あるか。

## 7. タイトル

- 問いの形か、対象を明示する形にする。煽らない。
- 型の分類（分析用。`articles/index.csv` の `title_type` に記録する）
  - `question`（問い型）：「私たちはなぜ『暇』に耐えられないのか」
  - `verify`（検証型）：「黄金比は本当に美しいのか」
  - `classic`（古典型）：「セネカ『人生は短いのではない』を現代に読む」
  - `concept`（概念型）：「疲労社会――『できる』ことが私たちを疲れさせる」

## 8. 配慮事項

- 研究者・人物への言及では、方法と主張を批判する。人格を批判しない。
- 医療・健康・法律について助言をしない。研究の紹介にとどめ、必要に応じて専門家への相談を促す。
- 性差・子育て・障害・民族などのテーマでは、事実（研究結果）と規範（どうあるべきか）を厳密に分ける。
- 図版は自作するか、権利が明確な素材だけを使う。
- 他の記事と同じ内容を繰り返さない（`scripts/ideas.py dup` と Editor D で確認する）。
