# Bundled fallback fonts (SIL Open Font License 1.1)

These are used when the Adobe Fonts named in tokens/tokens.json are not available
(cloud rendering, CI, a Mac without Creative Cloud fonts activated).

| File | Family | Source |
|---|---|---|
| CormorantGaramond-*.ttf | Cormorant Garamond (Christian Thalmann) | Google Fonts, OFL 1.1 |
| ZenOldMincho-*.ttf | Zen Old Mincho (Yoshimichi Ohira) | Google Fonts, OFL 1.1 |
| NotoSansJP-*.ttf | Noto Sans JP (Google / Adobe — same design as Source Han Sans) | Google Fonts, OFL 1.1 |
| Inter-*.ttf | Inter (Rasmus Andersson) | Google Fonts, OFL 1.1 |
